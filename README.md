# Apache Fineract Manual QA Project

## Project Overview

This repository contains a complete Manual QA project for the Apache Fineract Core Banking System.

The objective of this project is to demonstrate the complete Software Testing Life Cycle (STLC) for a banking application, including requirement analysis, test planning, test design, test execution, defect reporting, SQL validation, API testing, and traceability.

---

## Domain

**Banking**

Apache Fineract is an open-source Core Banking Platform used for managing:

- Customer Management
- Savings Accounts
- Loan Management
- Fixed Deposits
- Recurring Deposits
- Transactions
- User Management

---

## Project Objectives

- Understand banking business requirements
- Create professional QA documentation
- Design manual test scenarios
- Write detailed test cases
- Execute test cases
- Report defects
- Validate database records using SQL
- Perform API testing
- Prepare Requirement Traceability Matrix (RTM)
- Produce Test Execution Reports
