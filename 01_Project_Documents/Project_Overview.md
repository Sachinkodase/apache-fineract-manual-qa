# Project Overview

## Project Name

Apache Fineract Manual QA Project

---

## Domain

Banking

---

## Project Description

Apache Fineract is an open-source Core Banking System (CBS) that provides banking services such as customer management, savings accounts, loan management, deposits, and financial transactions.

This repository demonstrates the complete Manual Testing process for Apache Fineract following industry-standard QA practices.

---

## Project Objective

The objective of this project is to validate the functionality, reliability, usability, and security of the Apache Fineract banking application through comprehensive manual testing.

---

## Scope

The testing scope includes:

- Login & Authentication
- Client Management
- Savings Accounts
- Loan Management
- Fixed Deposits
- Recurring Deposits
- Transactions
- User Management
- Reports
- Audit Logs
